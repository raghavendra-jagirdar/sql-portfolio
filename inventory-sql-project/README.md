# Inventory SQL Project

This project simulates a simple inventory management system using SQL.

## Database Tables
- products
- inventory
- sales

## Concepts Demonstrated
- Primary Keys
- Foreign Keys
- INNER JOIN
- LEFT JOIN
- GROUP BY
- Aggregation (SUM)
- Business reporting queries

## Reports Included
1. Product stock report
2. Low stock alert
3. Total quantity sold per product
4. Inventory value report
5. Sales history

## Purpose
This project demonstrates SQL skills for inventory tracking and reporting,
similar to real-world business operations and analytics tasks.
