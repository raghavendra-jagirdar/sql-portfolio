# SQL Portfolio
SQL learning, scenarios, and mini projects

This repository contains SQL practice scenarios and projects demonstrating real-life business reporting and data analysis.

## 📌 Scenarios Covered

### Scenario 1 — Sales & Product Analysis
- Total quantity sold per product
- Top-selling products
- Average quantity sold per product

### Scenario 2 — Management Reporting
- Latest orders
- Customer order counts
- Top customers by number of orders
- Orders within date ranges
- Summary reporting

### Scenario 3 — Inventory & Business Insights
- Low stock reporting
- High-value products analysis
- Mid-range product identification
- Average & min/max pricing
- Sales performance insights

## 🧠 Skills Demonstrated
- SELECT, WHERE, numerical filtering
- Aggregate functions: COUNT, SUM, MIN, MAX, AVG
- GROUP BY and HAVING
- ORDER BY and LIMIT
- INSERT, UPDATE, DELETE

## 📁 Usage
Each scenario is stored in its own `.sql` file once added.
